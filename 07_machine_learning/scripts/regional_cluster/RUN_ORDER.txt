PRESERVED REGIONAL SCIENTIFIC SCRIPTS
=====================================

The public repository contains the four scripts required to inspect and audit
the preserved regional result products:

1. 01_run_regional_analysis.py
2. 03_run_hierarchical_benchmark.py
3. 06_exact_event_medians_and_radius_models.py
4. 07_redesign_regional_report.py

These are historical scientific-provenance implementations and expect the
authorised development workspace described in docs/FULL_PIPELINE_RUNBOOK.md.
They are not the supported first command for a new student.

For a clean executable teaching/scientific-core run, use from repository root:

    python scripts/run_pipeline.py --config config/demo.yaml

or replace config/demo.yaml with the ignored local config/scientific.yaml.

No absent script is implied by this run-order file.
