# 05 Environmental Predictors

## Scientific question
Which measurable catchment characteristics might relate to spills?

## Inputs
Validated catchments and external spatial/operational sources.

## Code to run
Area-weighted extraction and key-preserving joins.

## Outputs
Scientific predictor master with units and coverage metadata.

## QC and validation
CRS/coverage, row preservation, compositions, missingness and no target leakage.

## Connection to the next stage
The predictor matrix enters univariate and predictive models.

The public demo exercises the portable core. Full-scale scripts require omitted source data described in `../DATA_AVAILABILITY.md`.
