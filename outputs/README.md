# Outputs

This folder contains the smallest professor-facing evidence set.

- `headline_tables/` contains verified counts, outcome definitions, the univariate summary, both machine-learning scorecards and feature-importance summaries.
- `headline_figures/` contains final PDF and PNG figures for rapid review, including the original selected-sensor pathway and the later regional-cluster comparison.
- `demo/` is regenerated by `scripts/run_reproducible_demo.py` and is labelled **DEMONSTRATION ONLY - NOT THE SCIENTIFIC RESULTS**.

Raw EDM records, scientific master tables, rasters and licensed spatial datasets are intentionally absent. See `../DATA_AVAILABILITY.md` and `../docs/FIGURE_PROVENANCE.md`.
